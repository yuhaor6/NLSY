Issue P1-1 (FIXED): Missing `.wf-table td.num` right-alignment CSS
  Slide: 13 (Appendix A — waterfall table)
  Symptom: Number columns in the sample waterfall table were left-aligned.
  Fix: Added `.wf-table td.num{text-align:right;font-variant-numeric:tabular-nums;
       font-weight:600;}` to the CSS block.

Issue P1-2 (FIXED): `.img-panel` default `flex:1` consuming full column height
  Slide: 10 (Exploratory Diagnostics)
  Symptom: The img-panel was set to flex:1, which would expand to fill the entire
       right column, pushing the bullet list and callout below out of view.
  Fix: Added `style="flex:none;align-items:center;"` to the img-panel div so it
       does not grow and crowd out the content below it.

Issue P1-3 (FIXED): `rb-lbl` subscripts unreadable at ~8px
  Slides: 9 (BSX results), 7 (ETI results)
  Symptom: `ε<sub>w</sub>` inside `.rb-lbl` (12px base) renders subscripts at ~8px,
       which is illegible in print and on screen.
  Fix: Replaced all `ε<sub>w</sub>` in result-box labels with `ε_w` plain
       underscore notation throughout.

Issue P1-4 (FIXED): Slide 7 img-pair max-height too large for available space
  Slide: 7 (ETI Results)
  Symptom: First-stage images set to max-height:300px; available space below the
       dtable was approximately 255px, causing images to overflow.
  Fix: Reduced img max-height to 230px; added `flex:1;min-height:0;` to the
       .img-pair container to correctly constrain the pair within remaining space.

Issue P2-7 (FIXED): CSS cascade — `ul.small` not overriding `ul li` specificity
  Symptom: Adding class="small" to a `ul` element did not change its `li` font-size
       because `.slide-body ul li{font-size:19px}` (specificity 0-1-1) overrides
       `.small{font-size:17px!important}` applied to the ul. Since `!important` is
       on the ul selector, not the li, it does not cascade to children.
  Fix: Added CSS rule `.slide-body ul.small li{font-size:17px!important;
       line-height:1.44;}` to make the small class on a ul cascade to all its li
       children.
